# Claude Linux Launcher 概要

`Claude-StartUpTools-New-Linux` は、Linux 上で Claude Code をローカル起動し、複数プロジェクトを Supervisor 管理するための運用ツールです。

## 目的

- `/home/kensan/Projects` 配下の Git リポジトリを起動候補として扱う
- SSH 接続を使わず、ローカルの `claude`、`tmux`、`cron`、`systemd` を使う
- 個別プロジェクトと全登録プロジェクトの Supervisor 適用を切り替える
- 最終決断だけを人間が行い、それ以外の開発実務は CTO Claude に任せる

## 主要入口

| コマンド | 用途 |
|---|---|
| `./start.sh` | 運用メニューを開く |
| `bash bin/start-claude.sh` | 対話的にプロジェクトを選んで Claude 起動 |
| `bash bin/monitor-sessions.sh` | セッション監視と Supervisor 操作 |
| `bash bin/autonomy.sh start --all --dry-run` | 全適用対象の確認 |
| `bash bin/autonomy.sh start --all --yes` | 全適用の実行 |

## 対象外

- SSH 経由の起動
- PowerShell / Pester / Windows Terminal
- リモートホストへのスクリプト配布
