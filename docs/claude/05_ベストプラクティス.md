# ベストプラクティス

## 起動前

- `bash bin/autonomy.sh start --all --dry-run` で対象を確認する
- 大量適用時は `--yes` の前に不要プロジェクトを `config/config.json` の `localExcludes` へ入れる
- このランチャー自身は全適用対象から除外する

## 自律開発

- CTO Claude は調査、実装、テスト、レビュー、PR準備まで進める
- 人間は公開、merge、課金、Secrets、破壊的削除、全適用実行などの最終判断を行う
- 変更後は `npm test` と `npm run lint` を通す

## 色と表示

運用メニューは灰色表示を使わず、青、緑、黄、マゼンタ、赤、白を中心にしています。
