# セットアップ

## 前提

```bash
sudo apt-get update
sudo apt-get install -y git jq tmux nodejs npm bats shellcheck
```

Claude Code CLI は `claude` コマンドとして実行できる状態にしてください。

## 初期設定

```bash
cp config/config.json.template config/config.json
npm install
npm test
npm run lint
```

`config/config.json` は実機用のため Git 管理しません。標準では `projects` が `/home/kensan/Projects` を指します。

## 起動確認

```bash
./start.sh
bash bin/autonomy.sh start --all --dry-run
```

`--dry-run` は対象一覧だけを表示し、Supervisor 登録や Claude 起動は行いません。
