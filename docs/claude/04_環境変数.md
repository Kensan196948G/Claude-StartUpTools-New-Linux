# 環境変数

通常は `config/config.json` の `tools.claude.env` を使います。テストや一時実行では以下の環境変数で差し替えできます。

| 変数 | 用途 |
|---|---|
| `AI_STARTUP_CONFIG_PATH` | 読み込む設定ファイルを変更 |
| `AI_STARTUP_PROJECTS_DIR` | プロジェクト候補ディレクトリを変更 |
| `CCSU_STATE_FILE` | runtime state の場所を変更 |
| `CCSU_TMUX_BIN` | `tmux` コマンドのスタブ/差し替え |
| `CCSU_CRONTAB_BIN` | `crontab` コマンドのスタブ/差し替え |
| `CCSU_SUP_DIR` | Supervisor 状態ディレクトリを変更 |
| `CLAUDEOS_PLAIN_OUTPUT` | メニュー描画を色なしにする |

## 例

```bash
AI_STARTUP_PROJECTS_DIR=/home/kensan/Projects \
  bash bin/autonomy.sh start --all --dry-run
```
